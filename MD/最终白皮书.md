一、 双端物理隔离与体验架构 (Dual-Domain Architecture)

XuePilot 严格将“学习探索权”与“教研管理权”在物理（文件）层面切分，维护极致的产品沉浸感与商业化闭环。

1. The Explorer Deck (学生前台探索舱 - classroom.html)

定位：纯粹的 3A 级沉浸式 3D 学习与认知扩展空间。

净化原则：绝对禁止在此界面出现“生成大纲”、“编辑参数”、“配置数据库”等生硬的后端管理功能。所有数据库读取必须底层硬编码，经由 RLS 策略保障安全。

核心模块：

3D 知识星球 (Galaxy)：纯原生 Canvas 2D API 构建的高性能引力网格与曲率粒子，展示家长部署的学习任务。

全球教育智库 (Edu-Vault)：展示真实的不规则 K-12 教学大纲与开源教材库。支持极客级 3D 翻牌特效。此处仅限“阅览”和“一键申请建星”。

2. The Command Center (家控教研中枢 - dashboard.html)

定位：数据驱动、操作高效的家长/教师极客控制台。

门禁系统：由 Parent PIN (默认 0000) 守护，有效阻挡学生误入。

核心模块：

星系锻造中枢 (The Forge)：家长在此响应前端的建星请求，将现实教学计划转化为科幻知识星球并一键部署（包含 Quill 图文编辑器深度修改）。

全息学情雷达 (Insight Radar)：生成多维认知评估图谱（提问力、批判力、整合力）。

全局系统配置：统一收口大模型 (SYS/NOVA) 算力密钥的填写。

3. AI 指挥官模拟舱 (simulator.html / game.html)

定位：以“提问、判断、整合”为核心循环的独立专项训练游戏，把孩子逼到“项目经理”和“架构师”的位置上。

二、 全球智库、数据爬虫与消费生态 (Global Edu-Vault & Spider)

系统彻底摒弃低级的硬编码假数据，建立从深网抓取到前台消费的硬核数据链路。

1. 极致真实的异构数据结构

大纲（Syllabi）必须反映真实世界的不规则性（包含真实的 hours, objectives, key points）。

数据资产覆盖四大洲：北美核心（Common Core/NGSS）、英联邦经典、港台繁体底座、及前沿科技（AI/宇宙）。

2. Python 自动化工业级爬虫 (xuepilot_spider.py)

使用 requests/BeautifulSoup 等技术，穿透 OpenStax、Gutenberg、Simple English Wiki 等源头。

自动嗅探全书目录，执行深度遍历，清洗无用 HTML 节点，植入 XuePilot 专属的 TailwindCSS 样式标签，最后通过 Service Role Key 压入 Supabase 云端数据库。

3. 资产消费与全息阅读协议 (Asset Consumption Protocol)

爬虫抓取的海量名著与教材如何被孩子阅读？

静默拉取 (Silent Fetch)：前台 classroom.html 在初始化时，使用底层硬编码的 Supabase URL 和 Anon Key，通过 REST API 自动向云端的 edu_textbooks 发起读请求。

数据解包 (JSON Unpacking)：核心教材的图文数据被存储在数据库的 chapters_json 字段中，其结构为 [{"title": "章名", "content": "<html排版代码>"}]。

全息阅读器渲染 (E-Textbook Reader)：当孩子点击某本书的“提取阅读档案”时，系统绝不跳出外链。它会在当前界面弹出一个科幻双栏模态框。

左栏：遍历 chapters_json 生成动态导航目录 (TOC)。

右栏：将选定章节的 content (自带 HTML 与 Tailwind 样式) 直接注入阅读区，实现沉浸式、无需翻墙的极客阅读体验。

三、 苏格拉底引擎法则 (Socratic Engine Rules)

大模型指令 (Prompt) 必须严格遵循“接生术”与“管理即超能力”原则：

绝对不代写、不直给答案。

从“提问”开始，以“评估”结束：当孩子求助时反问；当给出方案后要求孩子找漏洞。

逻辑悖论镜：指出孩子文章中的“逻辑断裂点”，用问题引导其建立桥梁。

NOVA 伴读引擎：扮演一个听话的机器人，要求孩子“指挥”它去理解人类情感和复杂文本。

四、 模块化电影资产协议 (MCL Cinematic Protocol)

专为模拟舱 (simulator.html) 设计的 10-12s 帧同步编舞引擎。

资产解耦：视频只保留纯净的物理动态（如飞船抖动、灯光闪烁），无文字。

帧同步时间轴：

0.0 - 5.0s: 常态航行 (Ambient)。

5.0s: 目标锁定 (Lock)，HUD 触发红色锁定框与音效。

8.0s: 逻辑阻断 (Barrier)，视频出现物理阻碍，HUD 弹出交互卡片。

10.0 - 12.0s: 等待循环 (Idle)，视频进入无缝缓动循环，等待指挥官决策。

五、 商业化变现拦截网 (Monetization & Paywalls)

系统通过“能力阈值”和科幻包装进行优雅拦截，摒弃倒计时收费：

量子算力锁 (API Lock Paywall)：伴读/写作舱未绑定 API 时弹出：“演示模式：核心算力未接入，请联系指挥中心配置真实引擎。”

智库深度锁 (Vault Depth Paywall)：全球智库中仅开放少数基础资源免费预览。稀缺资源（新马英体系、高阶文学）打上 PRO 锁：“该档案已被量子加密封存，需要 PRO 权限进行外网解密。”

六、 前端技术极客规范 (Geek-Level Dev Rules)

技术栈统一：纯净的 HTML 单文件应用体系、TailwindCSS (视觉)、Alpine.js (状态驱动)、SweetAlert2 (科幻弹窗)、Quill.js (教案富文本)。

原生 3D 渲染：星系引力网格严格使用纯原生 Canvas 2D API，拒绝引入重型 3D 框架。

不妥协的完整性：代码迭代时绝不允许为缩减代码体积而阉割核心逻辑、删减资源列表（如 12大探索站点、书籍阵列）。必须输出可直接覆盖运行的完整文件。
