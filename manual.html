3. 第三方镜像/中转站 (国内免翻墙首选)

如果无法直连海外网络，无论是 Gemini 还是 GPT-4o，我们强烈建议您使用第三方的 API 中转平台（例如 Wildcard、API2D、或者 Github 上的开源代理）。

  • 如何配置：
    1. 将中转站提供的 Key 填入 API Key 框内。
    2. 关键：将中转站提供的服务器地址填入 API Base URL (代理节点) 框内。
    * 例如，您可以填入类似于 https://api.yourproxy.com/v1。系统转换网关会自动处理路由参数。
